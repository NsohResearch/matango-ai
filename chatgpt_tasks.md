# ChatGPT Tasks for Matango.ai Implementation

Based on the ChatGPT conversation, the following deliverables are required:

## Required Outputs

### A) Scripts (4 versions)
1. **Flagship Script (75-90s)** - YouTube/TikTok/IG/FB friendly with timestamps and on-screen text cues
2. **Shorts Script (45s)** - YouTube Shorts cut
3. **Reels/TikTok Script (25-30s)** - Short-form cut
4. **Agency Demo Script (60s)** - Professional demo version

### B) Storyboard Table
- Scene #, Duration, Visual, Dialogue, On-screen text, B-roll, Prompt (image), Prompt (motion/video)

### C) Matango Official Influencer Persona Spec
- Name, age range, vibe
- Voice: confident, no fluff, cinematic storytelling
- Speaking pace, pauses, emphasis words
- Visual style: cyber-noir, deep teal, high-contrast, clean studio lighting
- Camera rules: chest-up framing for key lines; occasional wide shot for product UI overlays
- Non-negotiables: never mention "tool parade" without naming 4-6 tools; always say "One Loop. One Brand Brain."

### D) Captions Pack
- 10 hooks (first line)
- 5 CTA variants
- 5 pinned comment variants
- 3 full video descriptions (platform-optimized)

### E) Lead Magnet CTA Copy
- "Matango Growth Loop Blueprint" - 2 versions (short + persuasive)

## Key Brand Positioning (Non-Negotiable)

### Taglines to incorporate:
- "One Loop. One Brand Brain. Always-On Growth."
- "End the marketing tool parade."
- "Stop hopping from tool 1 → tool 2 → tool 3…"

### Core Promise:
Matango.ai is an AI Marketing Agency platform that collapses the full marketing lifecycle into one place:
Brand Brain → Campaign Factory → Influencer Studio → Video Studio → Story Studio → Scheduler → Analytics → Auto-Insights

### Core Painkiller:
"Matango.ai eliminates workflow fragmentation by keeping brand memory + creation + publishing + optimization in one loop."

## Script Structure (Flagship 75-90s)

Beat 1: Cold open hook (0–10s)
Beat 2: Tool parade pain (10–25s) - MUST include emphatic "typical YouTube marketing tool parade" segment
Beat 3: Matango promise (25–35s)
Beat 4: Walkthrough: create influencer from one image (35–50s)
Beat 5: Generate 3 scenes (50–65s)
Beat 6: Turn image → video + story mode (65–80s)
Beat 7: CTA (80–90s)

## Tool Parade Pain Segment (REQUIRED)

"Most marketing videos go like this:
'Head over to tool #1 to write copy…
then tool #2 to generate images…
then tool #3 to edit…
then tool #4 to make videos…
then tool #5 to schedule posts…
then tool #6 to track analytics…'
And by the time you're done, your brand voice is broken, your assets don't match, and your week is gone."

Then pivot: "Matango.ai ends that parade. One loop. One brain. One place."

## Matango Product Terms to Use

- Brand Brain (persistent brand memory)
- Influencer Studio (create character from 1 image)
- Character Weight (recommend default 0.8)
- Keep Outfit toggle
- Create Image → Generate scenes → Send to Video Studio
- Video Studio: Image-to-Video + Lip Sync + Motion Sync
- Story Studio: "Day in the Life" story mode + preview-before-spend feature
- Library: asset versions + reuse across channels
- Schedule: post to YouTube/TikTok/IG/FB
- Analytics: auto-insights + A/B tests

## Style Constraints

- Gen-Z clarity but enterprise-grade credibility
- No hype words like "magic" more than once
- Avoid absolute claims ("kills," "destroys," "guarantees")
- Use "changes," "collapses workflow," "reduces time," "improves consistency"
- Keep it punchy. Short sentences. Strong transitions.
- No unverifiable earnings claims; keep "results vary" language
